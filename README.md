That spot was not missed; it was deprioritised. My lidar mapped it, my dustbin judged it, and my battery voted two-to-one to go home. That is the entry: one line, 133 characters, a robot vacuum's excuse for missing a spot, delivered deadpan in the machine's own voice. No apology, no cute observation about dust — just sensors, a dustbin with opinions, and a battery that outvoted everyone. The punch sits at the very end, where the vote is counted. This program writes the line to `/output/entry.txt` for the judge, after checking it stays one line of at most 200 characters.

## Run

```sh
python3 main.py
```
